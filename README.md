# Simple Interest Calculator

This project contains a simple Bash script that calculates simple interest based on user input.

The calculator asks the user to enter:

- Principal amount
- Annual rate of interest
- Time period in years

The simple interest is calculated using the following formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Simple and easy to use
- Runs from the terminal
- Accepts principal, interest rate, and time as user input
- Calculates and displays the simple interest

## Requirements

To run this project, you need:

- Bash
- `bc` command-line calculator
